# Гидронасос 400 — мод для Mindustry

Небольшой контентный мод для Mindustry: добавляет промышленный гидронасос размером **4×4**, который автоматически производит обычную воду на любой поверхности.

## Параметры

- **Выход:** до 400 единиц воды в секунду при полном питании.
- **Размер:** 4×4 клетки; спрайт — 128×128 пикселей (32 пикселя на клетку), без прозрачных пустот в основной текстуре.
- **Энергия:** потребляет 300 единиц мощности в секунду (5 единиц за тик); подключи насос к электросети.
- **Поверхность и месторождение:** не нужны; насос можно ставить на любой тип поверхности, в том числе на жидкие плитки.
- **Анимация:** крыльчатка гидронасоса вращается, когда блок получает питание.
- **Отвод:** жидкость можно забирать трубами со всех сторон.
- **Буфер:** 480 единиц. Если буфер заполнится, производство приостановится до отвода воды.

Производительность рассчитана для 60 игровых тиков в секунду: насос выдаёт 60 единиц за цикл длительностью 9 тиков, то есть `60 / 9 × 60 = 400` единиц воды в секунду. При нехватке питания скорость уменьшается.

## Установка в Steam Edition

1. Импортируйте файл **`water-well-400.zip`** через меню игры **Настройки → Моды → Импортировать мод**.
2. Перезапустите игру, если она попросит.
3. В режиме песочницы найдите блок **«Гидронасос 400»** в категории **«Производство»**. В кампании он появляется в ветке исследования после механического бура.

Для ручной установки положите ZIP (или распакованную папку, внутри которой сразу лежит `mod.hjson`) в каталог `mods` Mindustry. На Windows это обычно `%APPDATA%\Mindustry\mods`, на Linux — `~/.local/share/Mindustry/mods`, на macOS — `~/Library/Application Support/Mindustry/mods`.

## Изменение мода

Параметры блока находятся в `content/blocks/water-well.json`, а слои спрайта — в `tools/draw_sprite.py`. После правок пересоздайте PNG командой `python3 tools/draw_sprite.py`; затем пересоберите ZIP командой:

```sh
python3 build-mod.py
```

Мод использует только JSON-контент Mindustry — Java и дополнительные библиотеки не нужны. В `mod.hjson` указана минимальная версия build 146; поля блока выбраны из стандартного API JSON-модов Mindustry.
