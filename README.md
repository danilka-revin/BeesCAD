# Скважина 400 — мод для Mindustry

Небольшой контентный мод для Mindustry: добавляет промышленную скважину размером **4×4**, которая автоматически производит обычную воду на любой поверхности.

## Параметры

- **Выход:** до 400 единиц воды в минуту (6⅔ ед./с) при полном питании; при нехватке мощности скорость снижается.
- **Размер:** 4×4 клетки.
- **Энергия:** потребляет 300 единиц мощности в секунду (в параметрах Mindustry это 5 единиц за тик); подключи её к электросети.
- **Поверхность и месторождение:** не нужны; скважину можно ставить на любой тип поверхности, в том числе на жидкие плитки.
- **Анимация:** центральная турбина вращается, когда скважина получает питание.
- **Отвод:** жидкость можно забирать трубами со всех сторон.
- **Буфер:** 120 единиц. Если буфер заполнится, производство приостановится до отвода воды.

Скорость производства задана точно: 1 единица за 9 игровых тиков. При 60 тиках в секунду это `60 / 9 × 1 × 60 = 400` единиц в минуту. Расход энергии рассчитан отдельно: 5 единиц за тик × 60 тиков = 300 единиц в секунду.

## Установка в Steam Edition

1. Импортируйте файл **`water-well-400.zip`** через меню игры **Настройки → Моды → Импортировать мод**.
2. Перезапустите игру, если она попросит.
3. В режиме песочницы найдите блок **«Скважина»** в категории **«Производство»**. В кампании он появляется в ветке исследования после механического бура.

Для ручной установки положите ZIP (или распакованную папку, внутри которой сразу лежит `mod.hjson`) в каталог `mods` Mindustry. На Windows это обычно `%APPDATA%\Mindustry\mods`, на Linux — `~/.local/share/Mindustry/mods`, на macOS — `~/Library/Application Support/Mindustry/mods`.

## Изменение мода

Основные параметры блока находятся в `content/blocks/water-well.json`, а слои спрайта — в `tools/draw_sprite.py`. После правок спрайтов пересоздайте PNG командой `python3 tools/draw_sprite.py`; затем пересоберите ZIP командой:

```sh
python3 build-mod.py
```

Мод использует только JSON-контент Mindustry — Java и дополнительные библиотеки не нужны. В `mod.hjson` указана минимальная версия build 146; поля блока выбраны из стандартного API JSON-модов Mindustry.
