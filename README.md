# BeesCAD — параметрическое инженерное 3D-моделирование

**BeesCAD** — локальная CAD-платформа-прототип в духе Autodesk Fusion 360. Интерфейс использует графитовую палитру, янтарный акцент, компактный тулбар и панели проекта, вдохновлённые [linux_pcb_app / PsBees](https://github.com/danilka-revin/linux_pcb_app). BeesCAD — отдельный проект, не форк Fusion 360 и не часть PsBees.

Проект в первую очередь нацелен на **Ubuntu Linux**. Он запускается локально в браузере, хранит черновик в браузере и не требует облачной учётной записи.

## Что уже работает

- Дерево параметрической истории: выбрать, переименовать, скрыть, подавить, удалить операцию; отмена/повтор и маркер отката.
- Профильные эскизы (прямоугольник, круг, кольцо, слот, многоугольник) на рабочих плоскостях; редактирование размеров в инспекторе.
- Выдавливание с симметрией и уклоном, вращение, базовые тела, отверстия с цековкой/зенковкой, скругление, фаска, оболочка, линейный/круговой массив и зеркало.
- Каталог стандартных деталей: крепёж, шайбы, подшипник, шестерня с параметрами `m`/`z`, фланец, кронштейн, корпус РЭА и радиатор.
- 3D-вьюпорт: орбита, панорамирование, масштаб, быстрые виды, сетка, рабочие плоскости, сечение, измерение расстояния.
- Приближённые масса, объём, площадь и габариты по материалу; базовые DFM-предупреждения.
- Импорт STL/OBJ; экспорт бинарного/ASCII STL, OBJ, фасеточного STEP, SVG-проекций, DXF-контуров, BOM CSV и `.beescad.json`.
- Тёмная/светлая темы, палитра, настройка видимых панелей, локальное автосохранение.

### Ограничения CAD-ядра

Это **рабочий MVP, а не замена промышленному Fusion 360**. Эскизный решатель ограничений, полноценная топологическая история и точные аналитические поверхности пока не реализованы. Булевы операции используют экспериментальный mesh-CGS на треугольных сетках; результат зависит от качества сетки. Скругление/фаска и оболочка сейчас приближённые, не считайте их расчётом для выпуска документации. STEP формируется как фасеточный BREP, а не как точная NURBS-модель. Перед изготовлением проверьте экспорт в целевой САПР/слайсере и выполните инженерную проверку размеров и допусков.

## Быстрый запуск на Ubuntu

Нужны Git, Node.js 18+ и npm. Установщик поставит Node.js 24 LTS, если подходящей версии нет.

```bash
sudo apt update && sudo apt install -y git curl
git clone https://github.com/danilka-revin/BeesCAD.git ~/BeesCAD
cd ~/BeesCAD
bash install-ubuntu.sh
```

Установщик собирает приложение, копирует его в `~/.local/share/beescad` и добавляет ярлык **BeesCAD — инженерное 3D-моделирование** в меню приложений. Запускайте ярлык или команду:

```bash
~/.local/bin/beescad
```

Откроется `http://127.0.0.1:8485`. Не запускайте установщик через `sudo` целиком: Node.js он при необходимости установит через `sudo`, а само приложение должно остаться в вашей домашней папке.

### Запуск без установки ярлыка

В папке клона выполните:

```bash
cd ~/BeesCAD
bash run.sh
```

Первый запуск установит npm-зависимости и соберёт production-файлы, затем запустит локальный сервер и откроет `http://127.0.0.1:8080`. Если порт занят, выберите другой: `PORT=8090 bash run.sh`.

## Обновление

- При запуске через ярлык Ubuntu установленная версия проверяет GitHub и применяет новую версию, если она доступна.
- В приложении нажмите **«Обновить»** в тулбаре: проверка, прогресс скачивания/сборки и перезагрузка выполняются через локальный сервер.
- В исходном клоне `bash run.sh` подтягивает fast-forward обновление, если активна чистая ветка `main`.
- Ручная переустановка из клона: `cd ~/BeesCAD && bash install-ubuntu.sh`.

В режиме разработки `npm run dev` API автообновления намеренно не работает. Проверка обновлений доступна через установленный ярлык или production-сервер.

## Команды разработки

| Команда | Назначение |
|---|---|
| `npm run dev` | Vite dev-сервер с HMR, обычно `http://localhost:5173` |
| `npm run build` | TypeScript-проверка, сборка и предварительное Brotli/Gzip-сжатие |
| `npm start` | Production-сборка и локальный сервер `http://127.0.0.1:8080` |
| `npm test` | Проверки CAD-геометрии/CSG, экспорта и статического сервера |

Подробная инструкция для Ubuntu — **[INSTALL_UBUNTU.md](./INSTALL_UBUNTU.md)**.
