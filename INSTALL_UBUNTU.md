# Установка и запуск BeesCAD на Ubuntu

Ниже — пошаговая инструкция для **Ubuntu 22.04 / 24.04 / 25.04** (а также Linux Mint, Debian, Pop!_OS и других производных дистрибутивов). Опыт работы с командной строкой не требуется.

После выполнения инструкций у вас появится:
- быстрый запуск одной командой (`bash run.sh`) или
- полноценный ярлык **«BeesCAD — инженерное 3D-моделирование»** в меню приложений и на Рабочем столе (при клике запускается локальный сервер и открывается интерфейс программы в браузере),
- встроенное **автообновление из GitHub** (при запуске и по кнопке **«Обновить»** прямо в верхней панели программы).

---

## Вариант А — Быстрый запуск одной командой (без установки ярлыков)

Если вы уже скачали папку проекта и у вас установлен Node.js 18+:

```bash
cd ~/BeesCAD
bash run.sh
```

Скрипт `run.sh` сам:
1. Проверит наличие новых коммитов в GitHub (если вы на ветке `main` без локальных правок);
2. Установит зависимости (`npm ci` / `npm install`) при первом запуске;
3. Соберёт оптимизированную production-версию (`npm run build` с предсжатием `.br`/`.gz`);
4. Поднимет лёгкий локальный сервер на `http://127.0.0.1:8080` и откроет браузер.

Если порт `8080` занят:
```bash
PORT=8090 bash run.sh
```

## Вариант Б — Полная установка на Ubuntu с ярлыком в меню приложений

### Шаг 1. Откройте Терминал

Нажмите на клавиатуре сочетание клавиш **Ctrl + Alt + T** (или нажмите клавишу **Super/Windows**, наберите `Терминал` и нажмите **Enter**).

### Шаг 2. Установите Git (если ещё не установлен) и скачайте проект

Скопируйте команду ниже, вставьте её в Терминал (**Ctrl + Shift + V**) и нажмите **Enter**:

```bash
sudo apt update && sudo apt install -y git curl
```

Скачайте репозиторий BeesCAD в домашнюю папку и перейдите в него:

```bash
git clone https://github.com/danilka-revin/BeesCAD.git ~/BeesCAD
cd ~/BeesCAD
```

### Шаг 3. Запустите установщик `install-ubuntu.sh`

Выполните (важно: **без `sudo`**!):

```bash
bash install-ubuntu.sh
```

> **Примечание про Node.js:** Если в системе ещё нет Node.js 18 или новее, скрипт `install-ubuntu.sh` автоматически скачает и установит свежий **Node.js 24 LTS** (в этот момент он один раз попросит ваш пароль для `sudo`).

Что сделает установщик:
- Проверит актуальность исходников в GitHub;
- Установит зависимости и соберёт быструю production-сборку в `dist/`;
- Скопирует файлы приложения в `~/.local/share/beescad`;
- Создаст команду запуска `~/.local/bin/beescad` (порт по умолчанию `8485`);
- Создаст ярлык **«BeesCAD — инженерное 3D-моделирование»** в меню приложений Ubuntu и на Рабочем столе.

---

## Как запускать после установки

1. **Через меню приложений или Рабочий стол:** нажмите клавишу **Super (Windows)**, введите `BeesCAD` и кликните по иконке **«BeesCAD — инженерное 3D-моделирование»**.
2. **Из терминала:**
   ```bash
   ~/.local/bin/beescad
   ```
   (или просто `beescad` после перезахода в систему).
3. **Прямой адрес в браузере:** `http://127.0.0.1:8485` (при установке через `install-ubuntu.sh`) или `http://127.0.0.1:8080` (при запуске через `bash run.sh`).

## Как работает автообновление

В BeesCAD встроена система обновлений, идентичная `linux_pcb_app`:
1. **Прямо из интерфейса программы:** в верхней панели справа нажмите кнопку **«Обновить»** (или в тосте при появлении новой версии). Программа проверит ветку `main` на GitHub, покажет прогресс-бар скачивания и сборки, переключит сервер на новую сборку и автоматически перезагрузит страницу.
2. **При запуске с ярлыка или через `bash run.sh`:** лаунчер автоматически проверяет новые коммиты на GitHub и при их наличии обновляет приложение перед открытием окна.
3. **Переустановить свежую сборку вручную:**
   ```bash
   cd ~/BeesCAD
   bash install-ubuntu.sh
   ```

## Работа на слабом железе (Режимы производительности)

BeesCAD специально оптимизирован для быстрой работы даже на слабых ноутбуках, встроенной графике Intel HD / UHD и одноплатных ПК:
- **3D-рендер по требованию (On-Demand WebGL):** видеокарта рендерит кадр **только** при вращении камеры, редактировании геометрии или наведении — в покое нагрузка на CPU/GPU равна **0%**.
- **Автоопределение железа:** при старте программа проверяет число ядер (`hardwareConcurrency`), объём ОЗУ (`deviceMemory`) и тип видеокарты (включая программные драйверы `llvmpipe` / `Mesa OffScreen`) и автоматически выбирает профиль:
  - **Высокий (`high`)** — сглаживание MSAA, полный DPR (до 2x), тени и плавные эффекты;
  - **Сбалансированный (`balanced`)** — DPR до 1.5x, облегчённая сетка;
  - **Экономичный (`low` — для слабых ПК)** — DPR 1.0x, отключение `backdrop-filter`, теней, MSAA и тяжёлых сегментаций тел.
- Переключить режим вручную можно в любой момент кнопкой **«Производительность» (⚡)** на верхней панели или через **Вид → Производительность**.

## Удаление программы

Если вы захотите полностью удалить установленную копию:

```bash
pkill -f "beescad/server.mjs" || true
rm -rf ~/.local/share/beescad ~/.local/bin/beescad ~/.local/share/applications/beescad.desktop ~/Desktop/beescad.desktop ~/Рабочий\ стол/beescad.desktop
```
